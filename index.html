Developer Docs

Quickstart with Nexilo x402 SDK

Python Integration 
import nexilo

client = nexilo.Client(
    wallet_private_key="...",  # signs x402 spending ceiling
    max_budget_usdt=2.00       # $2 hard safety ceiling
)

response = client.chat.completions.create(
    model="llama-3.3-70b",
    messages=[{"role": "user", "content": "Hello Nexilo!"}],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content, end="", flush=True)

# On stream finish, on-chain receipt is verified automatically
